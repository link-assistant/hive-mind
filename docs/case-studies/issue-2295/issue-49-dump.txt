## Boundaries

- Do not reset or recreate the network to turn a failure into a pass
- Do not replace validator identities or reuse evidence from another network lineage
- Do not change core and DevShard in the same measured transition
- Do not patch official Gonka or DevShard source as a laboratory workaround
- A failed test is a result, not a reason to repeat the same cell until it passes
- A branch name, running process, container, HTTP health response, configured version, `ACTIVE` state, or one successful request is not acceptance
