Docker selected native authority admission, 2026-10-31 UTC

Root cause: Docker auth/history mount construction and host preparation ignored
explicit native adapter selectors. A root process could use canonical generation
G1 while its Docker task mounted conventional generation G0 instead. The native
selector was also omitted from the child environment. No projection existed.

Before repair, nineteen regression cases fail and three controls pass. Eighteen
cover each of six Codex, two Gemini and one Qwen auth/history selectors, including
explicit empty values. One uses two actual private synthetic credential files
with distinct generations and confirms the competing conventional authority.

or mount probes and in the launch argument builder. Preserve explicit Router
selection and vendor withholding. Keep the launch diagnostic structural, without
selected path values or credential contents. Unselected conventional behavior
and selectors belonging to another tool remain unchanged.
