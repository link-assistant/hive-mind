# Requirements traceability

| Requirement                                               | Source             | Implementation / evidence                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Operator can declare or provision a plugin or Agent Skill | Issue acceptance   | Explicit requirements are detected from issue title/body/all comments; providers are resolved from the Codex catalog.                                                                                                                                                                                                    |
| Auto-detect dependencies before Codex/Claude              | Maintainer comment | Codex plugin and Agent Skill requirements run before `codex exec`. Claude's existing project skill preparation remains unchanged; Codex-specific marketplace semantics are not imposed on Claude.                                                                                                                        |
| Generic, not Superpowers-specific                         | Issue and comment  | No plugin ID is hard-coded in provisioning. Skill providers are discovered from catalog source manifests. Only the documented transport suffix normalization is marketplace-specific.                                                                                                                                    |
| Apply per repository, not globally                        | Maintainer comment | State path is `$CODEX_HOME/hive-mind/repositories/<owner>/<repo>`.                                                                                                                                                                                                                                                       |
| Direct execution support                                  | Acceptance         | The preflight supplies scoped `CODEX_HOME` directly to the launched Codex process.                                                                                                                                                                                                                                       |
| Docker isolation support                                  | Acceptance         | Scoped state is under the already-mounted `.codex`; `.agents` is now propagated too.                                                                                                                                                                                                                                     |
| Persist across outer container restarts                   | Acceptance         | README and Docker documentation mount both persistent directories; scoped state lives beneath the mount.                                                                                                                                                                                                                 |
| Actionable exact failure                                  | Acceptance         | `CodexCapabilityPreflightError` includes unresolved identifiers and catalog/snapshot remediation.                                                                                                                                                                                                                        |
| Do not modify target repository                           | Acceptance         | All plugin and skill state is outside the checkout; tests assert path placement and Docker mounts.                                                                                                                                                                                                                       |
| Tests for direct, Docker, missing, success                | Acceptance         | `tests/codex-capability-preflight.test.mjs` covers all four plus restart/config refresh.                                                                                                                                                                                                                                 |
| Explain `.codex`, `.agents`, image config                 | Acceptance         | README, `docs/DOCKER.md`, and `docs/CONFIGURATION.md` document all interactions.                                                                                                                                                                                                                                         |
| Preserve effective feature config such as `multi_agent`   | Issue context      | Parent runtime config is refreshed into scoped config while plugin blocks remain scoped.                                                                                                                                                                                                                                 |
| Download and analyze all exposed evidence                 | Maintainer comment | `data/incident.md` and `data/experiments.log` preserve the exposed report and experiments; the evidence index states the unavailable private stream limitation.                                                                                                                                                          |
| Deep online research and similar components               | Maintainer comment | `research.md` records primary sources and component assessment; `analysis.md` compares alternatives.                                                                                                                                                                                                                     |
| Upstream reporting where applicable                       | Maintainer comment | Research found no defect in Superpowers or Codex: current official instructions and CLI agree. The incident is Hive Mind lifecycle integration plus an environment-facing alias, so a duplicate upstream issue would be misleading. The original blocked task is the appropriate related-repository notification target. |
| Entire codebase propagation                               | Maintainer comment | Direct launch, nested Docker mounts, outer deployment docs, configuration docs, release note, and regression tests are updated together.                                                                                                                                                                                 |
