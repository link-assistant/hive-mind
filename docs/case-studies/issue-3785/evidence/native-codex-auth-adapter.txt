Second-stage source experiment: coordination.patch serializes native manager
refresh/login/logout/identity writes and account-grant exchange leases, reloads
canonical auth before use and before exchange, checks the predecessor before
commit, and bounds exchange/wait duration. make_coordination_patch.py parses
and formats the changed Rust; apply_coordination.py verifies immutable manager
source and the exact storage module before mutation. Syntax/applicability and
the corrected workflow pass local checks. These are not native runtime passes.
The CI workflow requires explicit actual-manager negative controls first, then
rebuilds and requires positive replacement/logout/one-exchange controls, then
builds the full native CLI. These results remain pending.

The manager controls now also pause an actual native refresh at the loopback
provider while a second native process attempts login or logout. The negative
control requires that competing write to finish before the exchange response;
the coordinated case requires the writer to wait, both processes to succeed,
and the login/logout result to remain canonical. The full-CLI probe includes
native API-key reauthentication and explicit environment-key refusal. These are
prepared checks, not successful native runtime results.
