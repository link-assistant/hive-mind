== 3. Model filtering in B ==
B@98311466   if(W.cost.input===0)continue;delete Z.models[Y]
             This is in the "opencode" provider loader. With no API key the
             apiKey is "public", and every model whose cost.input is not 0 is
             deleted. So without a key only free models remain.
             Note: in C, opencode/gpt-5-nano has cost.input=0.05, so it is
             hidden without a key, although Zen lists it as free.
B@98335591   Models with status "alpha" are deleted unless
             enableExperimentalModels is set. Models with status "deprecated"
             are always deleted.

   entry that survives is "big-pickle". So the effective default is
   opencode/big-pickle.
=> OpenCode has no short alias table (no sonnet/opus/...). `-m` takes
   provider/model. Any alias handling must stay in Hive's catalogue.

== 6. Recommendation for Hive opencodeModels ==
 - Set default 'grok-code-fast-1' -> 'big-pickle' (opencode/big-pickle). This
   matches OpenCode's own keyless default (section 4).
 - Remove or retarget grok, grok-code and grok-code-fast-1 (deprecated).
 - claude, sonnet -> anthropic/claude-sonnet-5-5
   opus           -> anthropic/claude-opus-5-5
   haiku (new)    -> anthropic/claude-haiku-5-5
   gemini         -> google/gemini-3.1-pro-preview
   gpt4, gpt4o    -> openai/gpt-6-sol (or drop them; gpt-4 is deprecated)
 - Add the free Zen IDs as opencode/<id>: nemotron-3-ultra-free,
   nemotron-3.5-lightning-free, ling-3.1-flash-free, exo-free,
   step-5-preview-free, mimo-v2.6-flash-free, longcat-2.5-preview-free.
 - Better still: list models via `opencode models` (or `--refresh`) at runtime
   instead of a static list, because the free set changed between two runs on
   the same day (section 2).
