# Состояние pull request (languages: [en](PULL-REQUEST-STATUS.md) • [zh](PULL-REQUEST-STATUS.zh.md) • [hi](PULL-REQUEST-STATUS.hi.md) • ru)

У pull request, открытого Hive Mind, есть три состояния, и только последнее означает «его можно вливать».

| Состояние                            | Что означает                                                                                             | Что делать                             |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| **Черновик (draft)**                 | Hive Mind ещё работает: идёт сессия или CI/CD ещё не зелёный.                                            | Подождать.                             |
| **Готов к ревью (ready for review)** | Hive Mind подтвердил, что pull request можно влить — в режимах доведения до mergeable это и есть сигнал. | Проверять.                             |
| Комментарий **`✅ Ready to merge`**  | Все проверки CI/CD проходят, конфликтов слияния нет.                                                     | Влить или доверить это `--auto-merge`. |

В описании pull request есть блок **🚦 How to read this pull request status**, где указан активный режим из перечисленных ниже; комментарии рабочих сессий повторяют то же самое одной строкой. Если читать только что-то одно, читайте этот блок: он называет сигнал, которого нужно дождаться.

> Почему это важно: в [`Time0utXC/digitalstructures.pro#4`](https://github.com/Time0utXC/digitalstructures.pro/pull/4) pull request влили, пока ИИ ещё работал над ним. Незавершённая работа — и потраченные на неё ресурсы ИИ — пропали. См. [issue #2246](https://github.com/link-assistant/hive-mind/issues/2246).

## Режимы

### `--auto-restart-until-mergeable` (по умолчанию)

Hive Mind работает до тех пор, пока pull request не станет mergeable: проходят **все** проверки CI/CD — включая те, что выглядят не связанными с задачей, — и у ветки нет конфликтов с базовой. Всё это время pull request остаётся черновиком. Когда состояние подтверждено, Hive Mind сам снимает черновик и пишет комментарий `## ✅ Ready to merge`. Этот комментарий — ваш зелёный свет; слияние выполняете вы.

### `--auto-merge`

То же самое, но затем Hive Mind вливает pull request за вас. Подразумевает `--auto-restart-until-mergeable`.

### `--no-auto-restart-until-mergeable`

Одна рабочая сессия, без последующего наблюдения за CI/CD. Пока сессия идёт, pull request — черновик, а по её завершении помечается готовым к ревью, — **CI/CD в этот момент может ещё идти или падать**, и комментарий `✅ Ready to merge` не публикуется. Здесь «готов к ревью» означает ровно это: посмотрите его.

## Кто владеет флагом черновика

Hive Mind, а не ИИ-исполнитель.

- Pull request создаётся с `gh pr create --draft`, после чего состояние **перечитывается**: репозиторий, где черновики запрещены, молча игнорирует флаг, поэтому pull request переводится в черновик явно, если он был создан готовым к ревью.
- Каждая рабочая сессия в начале переводит pull request в черновик.
- В режимах доведения до mergeable переход в «готов к ревью» **удерживается**, пока состояние не подтверждено. Если ИИ-исполнитель или человек снимет черновик посреди запуска, Hive Mind вернёт его и запишет в журнал `⏸️ PR stays draft`.
- Завершённый запуск никогда не оставляет pull request черновиком. На любом пути выхода — обычное завершение, `CTRL+C` или фатальная ошибка — удержание снимается и pull request помечается готовым к ревью.

То же самое сказано и в подсказках для ИИ-исполнителя, одной строкой: он не должен менять состояние pull request сам, состоянием управляет система Hive Mind, а цель его работы — _mergeable_ pull request, то есть любая падающая проверка это его задача, даже если она выглядит не связанной с выданной ему задачей.

## Если состояние оказалось неожиданным

| Что вы видите                                           | Что это значит                                                                                                                                                    |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Черновик, а последний комментарий — о завершении сессии | Сессия закончилась; в режиме доведения до mergeable Hive Mind теперь следит за CI/CD. Об этом сказано в самом комментарии.                                        |
| Готов к ревью, но комментария `✅ Ready to merge` нет   | Либо запуск идёт в режиме `--no-auto-restart-until-mergeable`, либо наблюдение остановилось — причину объясняет комментарий об остановке (таймаут, лимит оплаты). |
| `⏸️ PR stays draft` в журнале                           | Кто-то запросил «готов к ревью», пока действовало удержание; черновик был восстановлен.                                                                           |
| `✅ Ready to merge`, а затем новые коммиты              | Кто-то запушил после подтверждения. Следующая проверка перепроверит состояние, и pull request может вернуться в работу.                                           |
