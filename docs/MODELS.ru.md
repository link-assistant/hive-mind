# Модели: живой каталог, `/models` и `hive-models` (languages: [en](MODELS.md) • [zh](MODELS.zh.md) • [hi](MODELS.hi.md) • ru)

Модель, выпущенная провайдером сегодня утром, бесполезна, если Hive Mind знает
только тот список, с которым был опубликован. Эта страница описывает, как Hive
Mind узнаёт, что существует **прямо сейчас**, как его об этом спросить, и одно
правило, вокруг которого построен весь механизм: **получение списка моделей
никогда не должно стоить вам токенов.**

> **⚠️ ЭКСПЕРИМЕНТАЛЬНО.** Живые источники — это новое (issue
> [#2202](https://github.com/link-assistant/hive-mind/issues/2202)). Встроенный
> каталог новым не является: это тот же список, по которому Hive Mind всегда
> проверял `--model`, и он остаётся ответом, когда ни один живой источник
> недоступен. Ничто здесь не может привести к падению задачи — источник с
> ошибкой просто отмечается и пропускается.

## Спросить, что доступно

```bash
# Все инструменты, из кэша.
hive-models

# Только Codex.
hive-models --tool codex

# Claude, с окнами контекста, ценами и происхождением, игнорируя кэш.
hive-models --tool claude --details --refresh

# Машиночитаемый вывод.
hive-models --json | jq '.tools.claude.liveOnly'
```

В Telegram тот же список — это `/models`, и он принимает те же аргументы в
снисходительной форме: `/models --tool codex`, `/models --tool=codex` и
`/models codex` означают одно и то же, потому что чат — это не shell:

```
/models
/models codex --details
/models --all
```

`/models` без аргументов отвечает про `claude`; `--all` отправляет по одному
сообщению на каждый инструмент.

## Как читать ответ

```
Models for claude (default: opus)
3 bundled and live · 2 hot loaded · 14 bundled only

Bundled and live (3) — shipped with this installation and confirmed reachable now
  * claude-opus-5 (opus, opus-5) [1M ctx · 128K out · $5/$25 per Mtok · reasoning · text+image+pdf · 2026-07-24]
    claude-sonnet-5 (sonnet, sonnet-5)
    ...

Hot loaded (2) — a live source has them, this installation does not ship them
    claude-fable-5-2
    ...

Bundled only (14) — shipped, but no live source confirmed them
    ...

Sources, in the order they are trusted:
  - Link.Assistant Router: ok — 41 model(s)
  - Anthropic GET /v1/models: skipped — ANTHROPIC_API_KEY is not set
  - models.dev: ok — specifications for 3570 model(s)
  - Bundled with this installation: ok — 17 model(s)

Live answers are cached for 1h 0m; pass --refresh to ignore the cache.
```

Три группы — это и есть смысл команды:

| Группа               | Означает                                                                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Bundled and live** | Поставляется здесь **и** подтверждена живым источником. Можно пользоваться.                                                                  |
| **Hot loaded**       | Есть у живого источника, но не поставляется с этой установкой. Доступна уже сейчас.                                                          |
| **Bundled only**     | Поставляется здесь, но ни один живой источник её не подтвердил — снята, переименована или недоступна вашей учётной записи. Может и работать. |

`*` отмечает модель по умолчанию для инструмента. Имена в скобках — это
псевдонимы, которые можно передавать в `--model`. `--details` добавляет
характеристики и источники, из которых пришла каждая модель.

При `HIVE_MIND_MODELS_HOT_LOAD=0` третья группа называется просто **Bundled**:
раз живые источники не опрашивались, назвать модели «неподтверждёнными» было бы
обвинением, которое команда не может обосновать.

## Откуда берётся список

Источники опрашиваются в этом порядке, и он же задаёт приоритет, когда два из
них описывают одну и ту же модель:

| #   | Источник                   | Даёт        | Почему ему доверяют именно здесь                                                                                                     |
| --- | -------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | Link.Assistant Router      | доступность | Шлюз, с которым реально говорит маршрутизируемая задача. Только он знает, достижима ли модель _по тому пути, которым пойдёт задача_. |
| 2   | `codex debug models`       | доступность | Установленный бинарник Codex отвечает из собственного каталога — без сетевого запроса и авторитетно о том, что он примет.            |
| 3   | Anthropic `GET /v1/models` | доступность | То, на что даёт право этот API-ключ.                                                                                                 |
| 4   | OpenAI `GET /v1/models`    | доступность | Та же форма, те же рассуждения.                                                                                                      |
| 5   | models.dev                 | метаданные  | Окна контекста, цены, модальности, даты выпуска. **Никогда** не добавляет модель в список доступных — только аннотирует.             |
| 6   | Встроенный в эту установку | доступность | `src/models/catalog.mjs`. Есть всегда; ответ, когда всё остальное недоступно.                                                        |

Источник-роутер опрашивается только тогда, когда роутер уже доступен или его
можно поднять локально; роутер оператора (`HIVE_MIND_ROUTER_URL`) используется,
но эта команда никогда его не запускает и не останавливает. См.
[Изоляция через роутер](./ROUTER.ru.md).

## Получение списка моделей никогда не стоит токенов

Issue #2202 формулирует это как жёсткое ограничение: _«извлечение моделей
никогда не должно приводить к расходу токенов, иначе такие методы должны быть
исключены из нашей кодовой базы»_. Это свойство **источников**, поэтому оно
проверяется там, где источник объявляется, а не в каждом месте вызова
(`src/model-catalogue-sources.lib.mjs`). Две избыточные защиты:

1. **`assertTokenFreeSource`** отвергает любой источник, который явно не объявил
   `billable: false`. Источник не может стать платным по умолчанию.
2. **`assertTokenFreeUrl`** отвергает любой URL, путь которого является
   completion-эндпоинтом, независимо от дескриптора. Опечатка, превращающая
   `/v1/models` в `/v1/messages`, бросает исключение вместо траты.

Вторая половина правила — запись о том, что **не** реализовано, чтобы «мы так не
делаем» было проверяемым утверждением, а не просто отсутствием:

| Отвергнутый метод                                    | Почему                                                                                                                                            |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Управлять выбором `/model` в TUI Claude Code         | Запуск TUI начинает сессию, а Claude Code отправляет запрос при её старте. Расход реален и невидим, и он ложится на чужой счёт.                   |
| Управлять выбором `/model` в TUI Codex               | `codex debug models` возвращает тот же каталог в JSON без сетевого запроса, так что TUI добавляет только стоимость и нестабильность.              |
| Проверять существование id через completion-эндпоинт | Даже один токен — это оплаченный запрос, а 404 для неизвестной модели неотличим от 404 для недоступной. `assertTokenFreeUrl` отвергает такой URL. |
| Парсить HTML документации провайдеров                | Бесплатно, но без версий и с привязкой к вёрстке. models.dev агрегирует те же характеристики за стабильным JSON-контрактом.                       |

## Кэширование

Живые ответы кэшируются **минимум на час**, отдельно по источнику и инструменту,
в каталоге состояния Hive Mind. `HIVE_MIND_MODEL_CATALOGUE_TTL_MINUTES` может
только _повысить_ этот порог: меньшее время жизни означало бы более частые
запросы к провайдерам, а именно ради этого кэш и существует. `--refresh` (и
`/models --refresh`) игнорирует кэш на один запуск, не меняя сохранённый TTL.

Сбой источника не фатален и не портит кэш: используется последний удачный ответ
с пометкой `stale`, а сама ошибка печатается в списке источников, чтобы было
видно, _почему_ каталог выглядит именно так.

## Поддержание CLI в актуальном состоянии

Устаревший бинарник `claude` или `codex` — обычная причина, по которой имя
совсем новой модели отвергается, поэтому команды, которые его запускают, сначала
проверяют наличие новой версии: `/solve`, `/hive`, `/task`, `/fix` (через
дочерний `/solve`), `hive-models` и `/models`.

Проверка намеренно осторожна:

- **Не чаще раза в 6 часов**, с блокировкой состояния, чтобы параллельные
  запуски не мешали друг другу.
- **Откладывается, пока выполняются другие задачи.** CLI никогда не подменяется
  под чужим работающим solve. Каждый запуск исключает из этой проверки
  _собственную_ задачу — иначе механизм, определяющий занятость по командным
  строкам процессов, нашёл бы сам запуск, задающий вопрос, и откладывал бы
  обновление вечно.
- **Сужена** до того CLI, который команда собирается запускать. Просмотр моделей
  Codex не переустанавливает Gemini.
- **Никогда не фатальна.** Недоступность реестра не стоит вам ничего, кроме
  самого обновления.
- **Полностью пропускается** при `--dry-run` / `--only-prepare-command`, которые
  ничего не должны устанавливать.

Отключить для одного запуска — `--no-tool-update`, глобально —
`HIVE_MIND_AGENTIC_CLI_AUTO_UPDATE=0`.

## Конфигурация

| Переменная                              | Значение                                                                                                              |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `HIVE_MIND_MODELS_HOT_LOAD=0`           | Не обращаться к живым источникам вовсе; показывать только встроенный каталог                                          |
| `HIVE_MIND_MODELS_ROUTER=0`             | Пропустить именно источник-роутер, сохранив остальные живые источники                                                 |
| `HIVE_MIND_MODEL_CATALOGUE_TTL_MINUTES` | Поднять время жизни кэша выше порога в 60 минут                                                                       |
| `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`   | Включают соответствующий listing-эндпоинт провайдера. Отсутствие — не ошибка: источник просто пропускается            |
| `HIVE_MIND_AGENTIC_CLI_AUTO_UPDATE=0`   | Никогда не проверять агентные CLI на наличие новой версии                                                             |
| `HIVE_MIND_AGENTIC_CLI_UPDATE_ONLY`     | Список разрешённых CLI через запятую                                                                                  |
| `HIVE_MIND_AGENTIC_CLI_UPDATE_EXCLUDE`  | Список запрещённых CLI через запятую. Сужение от команды **пересекается** с этими списками и не может отменить запрет |
