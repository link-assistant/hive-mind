# Поведение, зависящее от модели

Каждая модель — Formal AI или LLM, с любым `--tool` — проходит через один и тот же код для промпта, системного промпта, обратной связи при перезапуске, переходов draft/ready, прерывателей циклов, классификации сбоев и тела pull request ([#2319](https://github.com/link-assistant/hive-mind/issues/2319)). Сессия с пустым diff считается неудачной для любой модели: pull request остаётся черновиком, а цикл перезапуска повторяет попытку с обратной связью.

Зависящее от модели поведение ограничено таблицей ниже. `git grep -c isFormalAiModel -- src` перечисляет ровно эти файлы.

| Поведение                               | Где                                                                                                                                   | Почему это не может быть общим                                                                                                                                                                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Подключение к endpoint и учётные данные | `formal-ai.lib.mjs`, `formal-ai-sidecar.lib.mjs`, `solve.validation.lib.mjs`, `agent.lib.mjs` (минимальная версия agent)              | Formal AI обслуживается `formal-ai serve`, а не поставщиком инструмента: каждый инструмент нужно направить на этот endpoint, а вход у поставщика не исправит ошибку авторизации.                                                                           |
| Совместимость с инструментами           | `models/index.mjs`, `formal-ai-model.lib.mjs`                                                                                         | Formal AI — одна модель, которую запускает любой инструмент; модели поставщиков работают только в своих инструментах.                                                                                                                                      |
| Строка версии и происхождения           | `session-runtime-provenance.lib.mjs`                                                                                                  | Лог сессии записывает версию бэкенда Formal AI так же, как версию инструмента, чтобы сбой можно было отнести к выпуску.                                                                                                                                    |
| Трейлеры атрибуции                      | `formal-ai-attribution.lib.mjs`                                                                                                       | `--attribution auto` включает трейлеры коммитов и доказательства Formal AI для запусков Formal AI ([#2230](https://github.com/link-assistant/hive-mind/issues/2230)).                                                                                      |
| Данные о ценах                          | `formal-ai-pricing.lib.mjs`, `agent.lib.mjs`, `codex.lib.mjs`, `gemini.lib.mjs`, `qwen.lib.mjs`, `anthropic-cost-accumulator.lib.mjs` | Formal AI бесплатен. Стоимость, которую сообщает инструмент, — это цена поставщика за модель, которая не запускалась, поэтому она игнорируется. Публичная оценка показывается один раз ([#2318](https://github.com/link-assistant/hive-mind/issues/2318)). |

## Удалённые расхождения

| Прежний путь Formal AI                                                   | Теперь                                                                                                                                                                                              |
| ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Заменённый промпт и пустой системный промпт (`formal-ai-prompt.lib.mjs`) | Тот же промпт, что у всех моделей ([#2313](https://github.com/link-assistant/hive-mind/issues/2313))                                                                                                |
| Playwright MCP отключался для Formal AI                                  | Одинаковое значение по умолчанию для всех моделей. Прерыватель повторных вызовов останавливает цикл браузера для любого адаптера ([#2316](https://github.com/link-assistant/hive-mind/issues/2316)) |
| `classifyFormalAiToolResult` переписывал `planned_not_executed`          | Общий контракт: при пустом diff PR остаётся черновиком, а сессия перезапускается с обратной связью ([#2312](https://github.com/link-assistant/hive-mind/issues/2312))                               |
| Прерыватель повторных вызовов только для Formal AI                       | Один прерыватель для всех адаптеров ([#2316](https://github.com/link-assistant/hive-mind/issues/2316))                                                                                              |

## Сквозная проверка

`.github/workflows/e2e-hello-world-matrix.yml` (ручной `workflow_dispatch`) запускает `solve` на новой задаче Hello World с `--model formal-ai` под `--tool claude`, `agent` и `codex`, а также с одной LLM-моделью в качестве контроля. Для каждой строки проверяется всё следующее:

- pull request готов к ревью;
- diff содержит только программу, workflow и тестовый скрипт;
- программа печатает ровно `Hello, World!`;
- workflow зелёный;
- тело PR пересоздано;
- нет комментария `🛑 Automation stopped`.

Проверки находятся в `scripts/e2e-hello-world.lib.mjs` и покрыты тестами в `tests/e2e-hello-world-matrix-2319.test.mjs`.

Workflow нужен секрет `E2E_GITHUB_TOKEN` — токен тестового пользователя с правом создавать репозитории. После запуска удалите созданные репозитории через `cleanup-test-repos.yml`.
