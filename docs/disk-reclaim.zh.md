# 自动回收磁盘空间

在 `solve` 或 `hive` 因磁盘空间不足而拒绝工作之前，Hive Mind 使用固定版本的
`disk-space-saviour` 清理符合条件的 npm、Bun、pnpm、pip、uv 和 Cargo 注册表缓存。
紧急清理限制在 **safe** 级别，达到所需可用空间后停止。只清理被检查的文件系统上的缓存。
随后磁盘检查会重新测量可用空间；缓存大小的估算值不能直接允许任务启动。

工作会话期间，每隔 30 分钟在任务工作目录内进行一次维护，AI 工具结束后再进行一次。
这些维护仅选择被新版本取代的 Rust 构建产物，并保留最新一代构建产物。
Cargo 或 rustc 运行期间，库构建产物受到保护。空闲的增量编译会话及旧的测试或示例
二进制文件可以在构建期间清理，但必须至少存放三小时，并通过打开文件检查。
DSS 会在删除前再次检查进程活动和 Git 文件跟踪状态。如果无法读取进程信息，就阻止清理。
整个 `target/` 目录、已安装的依赖和源代码都不属于此集成的清理范围。

| 环境变量                      | 默认值 | 用途                                                             |
| ----------------------------- | ------ | ---------------------------------------------------------------- |
| `HIVE_MIND_AUTO_RECLAIM`      | `safe` | 启用限定范围的安全清理；`off` 禁用 DSS 扫描和清理。              |
| `HIVE_MIND_RECLAIM_STALE_AGE` | `1h`   | Rust 活动时间窗口，例如 `2h`；DSS 对叶级产物保留更长的时间窗口。 |

不支持的模式会禁用 DSS 清理。`moderate` 和 `aggressive` 模式未启用。
模拟运行和仅准备命令的会话不会运行 DSS。现有的工作目录、代理快照及显式配置的
镜像清理策略独立于这些设置继续运行。

任务日志包含 `[DSS_SCAN]` JSON 摘要，记录大小、阻止清理的原因和扫描错误；
还包含 `[DSS_RECLAIM]` JSON 记录，记录每个操作的路径、状态和字节数。
最后一行给出持久化 DSS 审计文件的位置。扫描或清理失败时，仍由原有的磁盘检查决定是否启动。
设置 `DSS_DEBUG=1` 可跟踪 DSS 的底层命令及执行时间。

Dockerfile 在安装软件包的同一条 `RUN` 指令内清理 npm 和 Bun 下载缓存，
避免安装层保留下载归档。浏览器安装和全局代理命令行工具会保留。
从 Box 基础镜像继承的缓存仍占用下层空间；在派生镜像或运行中的容器内删除这些文件
不能释放相应空间。基础镜像必须清理自己的安装层。

## 容器维护边界

每次 DSS 扫描都传入 `docker: false`，不授予删除容器、镜像或卷的许可。
此集成不会调用 Docker 来停止、重启、检查或删除任务容器。
运行在任务容器中的求解器可以尝试维护本地工作目录；如果 DSS 无法验证进程，
它会跳过相关构建产物并报告阻止原因。

递归 DinD 维护及已结束容器的清理或删除依赖于
[disk-space-saviour#14](https://github.com/link-foundation/disk-space-saviour/issues/14)。
据报告，v0.13.1 的 DinD 探测无法验证打开的文件，而 Docker 可写层大小探测失败
可能丢弃整个扫描结果。这些操作仍被禁用。DSS 集成尚未实现
`HIVE_MIND_REMOVE_FINISHED_CONTAINERS`。以后启用删除时，无论任务退出代码如何，
都必须验证工作目录干净且提交已推送、任务日志已上传、`docker logs` 已保存，
并确认会话没有等待恢复。

## 验证

运行 `node tests/disk-reclaim-2294.test.mjs`。测试模拟可用空间为 10 MB、需求为 100 MB
的情况：缓存清理后实际可用空间为 120 MB，任务可以启动。即使报告的回收字节数很大，
实际可用空间没有增加时仍会拒绝启动。真实 DSS 测试使用临时 Rust 构建文件，
验证活动构建受到保护，并在 Cargo 结束后仅删除旧哈希产物。
定时器测试验证维护不会重叠，退出时会等待所有维护完成。
Dockerfile 检查确保每个安装层都清理缓存。

添加清理调用之前，复现测试失败（`attempts: 0`，预期为 `1`）。原始事件和剩余上游限制见
[问题 #2294](https://github.com/link-assistant/hive-mind/issues/2294) 及
[生产环境状态更新](https://github.com/link-assistant/hive-mind/issues/2294#issuecomment-6043144775)。
