## Rejected partial solutions

- **Agent alias only:** fixes the original error but not the expanded six-tool request.
- **Pass `formal-ai` directly to every CLI:** ignores that provider URL, key, config isolation, protocol, and model selector differ by client.
- **Always start a local server:** loses persistent memory and creates one server per isolated task.
- **Change Agent's default immediately:** contradicts the issue's “once fully supported” condition because the current issue-to-PR ladder remains 0/16.
- **Attach nested tasks to the outer Compose network:** the pinned start-command Docker backend exposes environment forwarding but no `--network` option. Parent-side HTTP name resolution plus endpoint propagation crosses the ordinary nested-Daemon DNS boundary without patching that dependency.
