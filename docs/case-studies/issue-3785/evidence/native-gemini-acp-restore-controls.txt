not instrument native module exports, SDK methods or protocol server methods.

Only synthetic credentials and a TLS-verifying loopback provider are used.

reaped, and failed synthetic fixtures are retained. The audit assertion selects
the actual conversation containing the later prompt; unrelated empty native
startup sessions may legitimately be archived during native cleanup.

adapter. Remaining native writers, plan/task memory, child/subagent execution,
legacy migration, interruption/power-loss durability, every backend's complete
lifecycle and production package/image/launcher integration remain unfinished.
